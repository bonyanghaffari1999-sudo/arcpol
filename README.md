# Arcpol Engineering Portfolio

رزومهٔ محلی مجموعهٔ مهندسی چندرشته‌ای با Vue 3 و Vite. پروژه‌های قبلی شرکت حفظ شده‌اند و گزارش‌های تصویری تلگرام جداگانه نمایش داده می‌شوند.

## اجرا و ساخت

نیازمندی‌ها: Node.js و وابستگی‌های ثبت‌شده در `package-lock.json`.

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 5174
npm run build
```

برای همگام‌سازی دستی گزارش‌ها:

```powershell
npm run sync:telegram
```

## پنل مدیریت محلی

در حالی که سرور توسعه اجراست، پنل را از `http://127.0.0.1:5174/#/admin` باز کنید. در آن می‌توانید پروژه‌ها و گزارش‌ها، مقاله و متن کاملشان، معرفی و خدمات شرکت، بازخوردهای محلی و رسانه‌های سایت را جست‌وجو و ویرایش کنید؛ رکورد تازه ابتدا پیش‌نویس است. بخش «رسانه‌ها و تصویرها» کتابخانهٔ تصاویر قابل‌نمایش، نشان سایت، تصویر صفحهٔ دربارهٔ ما، تصویر جایگزین مقاله‌ها و پروژه‌های صفحهٔ اصلی را مدیریت می‌کند. عکس‌های پرسنلی در همان بخش فقط به‌صورت محلی نگهداری می‌شوند و امکان جایگزینی با پشتیبان و بازگردانی دارند. عکس‌های هر پروژه و مقاله نیز در ویرایشگر همان مورد مدیریت می‌شوند. حذف رکوردهای موجود قابل‌بازگردانی است و آخرین ذخیرهٔ محتوا نیز نسخهٔ پشتیبان دارد.

ویرایش‌ها در `src/admin-overrides.json` جدا از خروجی تلگرام ذخیره می‌شوند و در اجرای مجدد همگام‌سازی باقی می‌مانند. تصویرهای تازه در `public/uploads/admin/` می‌مانند. بازخوردهای دارای اطلاعات شخصی در `data/admin-feedback.json` روی همین رایانه ذخیره می‌شوند و وارد نسخهٔ استاتیک عمومی نمی‌شوند. API مدیریت فقط روی loopback فعال است؛ این مسیر برای ویرایش محلی است و احراز هویت یا میزبانی عمومی ندارد.

## بات زندهٔ گروه تلگرام

برای راه‌اندازی بات گزارش‌دهی فقط در گروه کنترل و نظارت مهندسین مشاور غفاری، راهنمای [TELEGRAM-BOT-SETUP.md](./TELEGRAM-BOT-SETUP.md) را دنبال کنید. اعضا با `/new@نام‌کاربری‌بات` دسته را انتخاب می‌کنند و گزارش را با پاسخ مستقیم به پیام بات می‌فرستند؛ پیام‌های عادی و گروه‌های دیگر ذخیره نمی‌شوند. بات با Privacy Mode روشن و دسترسی عضو عادی کار می‌کند. توکن فقط در `.env.telegram.local` روی همین رایانه قرار می‌گیرد. خروجی بات در `.local-data` خصوصی می‌ماند و بدون بازبینی وارد سایت عمومی نمی‌شود.

```powershell
npm run telegram:discover-group
npm run telegram:bot
```

به‌صورت پیش‌فرض خروجی تلگرام در پوشهٔ `Telegram Desktop/ChatExport_2026-10-24` کنار پوشهٔ پروژه خوانده می‌شود. برای مسیر دیگر، متغیر `TELEGRAM_EXPORT_DIR` را تنظیم کنید. هنگام اجرای نسخهٔ توسعه، تغییر صفحه‌های پیام و عکس‌ها همگام‌سازی را دوباره آغاز می‌کند. اگر ورودی خالی باشد یا تعداد گزارش‌های قابل‌خواندن از snapshot فعلی کمتر شود، فایل‌های همگام‌شده و عکس‌ها نگه داشته می‌شوند.

## داده‌ها

- ۷۰ پروژهٔ قبلی شرکت و ۴۹ مقاله حفظ شده‌اند.
- snapshot کامل تلگرام ۹۱ گروه شناسه‌دار، ۱٬۹۶۹ گزارش مستقل و ۵٬۰۴۰ رویداد دارد. خروجی عمومی فقط ۸۵ گروه و ۷۱۸ گزارش مستقلِ عکس‌دار، در مجموع ۳٬۷۱۶ رویداد و ۳٬۷۰۴ عکس منتخب را نگه می‌دارد.
- ۱٬۲۵۷ رکورد و ۱٬۳۲۴ رویداد فاقد عکس از خروجی عمومی حذف می‌شوند. رویدادهای بدون عکس در تایملاین پروژه‌های عکس‌دار نیز نمایش داده نمی‌شوند.
- کاربری صریحاً تجاری «تجاری» و موارد نامشخص «مسکونی» ثبت می‌شوند؛ خدمت نیز «نظارت» است، مگر متن منبع صریحاً دامنهٔ «نظارت و اجرا» را مشخص کند.
- موقعیت عمومی به شهر، محله یا منطقهٔ کلی محدود است. نشانی خیابان، پلاک و جزئیات مسیر از تایملاین حذف می‌شود؛ نکته‌های منفی یا دارای بار حقوقی به عبارت فنی خنثی تبدیل می‌شوند.
- عکس‌ها و تایملاین گزارش‌ها از جدید به قدیم مرتب هستند.
- فقط پیام‌های دارای شناسهٔ پایدار منبع در گروه‌های پروژه‌ای کنار هم قرار می‌گیرند. گزارش‌های دیگر مستقل می‌مانند و با پروژه‌های قبلی شرکت ادغام نمی‌شوند.
- `src/telegram-projects.json` و `src/telegram-reports.json` فقط محتوای عکس‌دارِ قابل‌نمایش را نگه می‌دارند. `src/telegram-sync-meta.json` شمار کامل رویدادهای منبع را برای کنترل همگام‌سازی‌های بعدی ثبت می‌کند.
- از هر رویداد تصویری با وضوح بالاتر از میان گزینه‌های منبع انتخاب می‌شود. عکس نهایی تنها هنگامی مشخص می‌شود که گزارش صریح تکمیل، همان عکس را داشته باشد.
- متن رویدادها از گزارش واقعی پس از حذف فیلدهای هویتی و تماس می‌آید. مرحله، پیگیری، رفع مشکل و تکمیل فقط وقتی نمایش داده می‌شود که متن منبع شاهد صریح داشته باشد.

## حفظ حریم خصوصی

نسخهٔ عمومی نام کارفرما و کارکنان، شماره‌های شخصی کارکنان، کد پستی، شماره‌های ثبتی و نشانی دقیق پروژه‌ها را نمایش نمی‌دهد. طبق تأیید مالک، تلفن دفتر، شمارهٔ مستقیم شرکت و نشانی دفتر مرکزیِ ثبت‌شده در سایت قدیمی در صفحهٔ تماس نمایش داده می‌شوند. موقعیت پروژه‌ها به شهر یا محدودهٔ کلی کاهش داده شده، نویسندهٔ مقاله‌ها با عنوان عمومی نمایش داده می‌شود و تصاویر پرسنلی در پوشهٔ محلی `tmp/private-team-assets` نگهداری می‌شوند و وارد ساخت عمومی نمی‌شوند.

## ساختار اصلی

- `src/App.vue`: فهرست، جزئیات، جست‌وجو، فیلترها و تایملاین
- `src/content.js`: معرفی مجموعه، خدمات و حوزه‌های مهندسی
- `src/site-data.json`: پروژه‌ها و مقاله‌های قبلی سایت
- `src/article-details.json`: متن‌ها و پیوست‌های ثبت‌شده برای مقاله‌ها
- `scripts/sync-telegram-export.mjs`: واردسازی و پاک‌سازی گزارش‌ها و انتخاب عکس
- `vite.config.js`: سرور توسعه و همگام‌سازی خودکار خروجی تلگرام
- `public/telegram`: تصاویر منتخب محلی

فرم بازخورد در اجرای محلی از API روی همین رایانه استفاده می‌کند و در صورت نبود آن به حافظهٔ مرورگر برمی‌گردد؛ اطلاعات به سرور عمومی فرستاده نمی‌شود.

این پروژه فعلاً محلی است. تنظیم میزبانی یا سایت منتشرشدهٔ متناظر در پوشهٔ پروژه پیدا نشد؛ برای انتشار، حساب/پروژهٔ میزبانی و تنظیمات مقصد لازم است.
